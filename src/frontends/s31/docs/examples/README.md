# Worked source examples

These chapters compute a small S31 program by hand and follow its retained
relation into circuit or AIR constraints:

- [Functional polynomial](worked-functional-polynomial.md): higher-order
  source syntax erases to four field operations on each lane.
- [Static sum](worked-static-sum.md): an enum choice and total unused payload
  erase, leaving one repeated-step relation node.

The [main guide](../README.md) puts these examples in the full reading order.

other nested Markdown chapter.
