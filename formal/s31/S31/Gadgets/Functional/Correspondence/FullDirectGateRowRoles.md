# Full direct-Gate row roles

The bounded direct-Gate profile uses **512 arithmetic rows**. The source-byte
checker admits between one and sixteen arithmetic instructions. Let `a` be
the number of source additions, `m` the number of source pointwise products,
and `n = a + m`. The add partition has `A = 476 - m` rows.

| Physical rows | Role | Count |
| --- | --- | ---: |
| `0..2` | public input pack adds | 3 |
| `3..(2+a)` | source adds | `a` |
| `(3+a)..(10+a)` | four input and four output ABI copies | 8 |
| `(11+a)..(A-1)` | constant derivation and padding adds | `465-n` |
| `A` | constant derivation subtraction | 1 |
| `(A+1)..(A+3)` | public input pack multiplies | 3 |
| `(A+4)..(A+6)` | public output inverse-basis multiplies | 3 |
| `(A+7)..(A+27)` | constant derivation multiplies | 21 |
| `(A+28)..(A+27+m)` | source pointwise products | `m` |
| `(A+28+m)..(A+31+m)` | public output masks | 4 |
| `(A+32+m)..(A+35+m)` | public input identity products | 4 |

The final endpoint is `A + 35 + m = 511`. There are `n` source rows, 25
public pack/unpack/copy rows, and `487-n` constant or padding rows.

For `square(x) = x .* x`, followed by `square .* square`, `a=0`, `m=2`,
`n=2`, and `A=474`. Rows `502` and `503` hold the two source products;
rows `11..473` are constant/padding adds, row `474` is the constant
subtraction, and rows `481..501` are constant multiplies. The four output
masks are rows `504..507` and input identity rows are `508..511`.

`FullDirectGateRowRoles.lean` proves this modeled partition from checked
source bytes. `SourcePhysicalAddressBounds.lean` separately proves modeled
source addresses and use counts fit the native field. The source-independent
constant gate *addresses and values* are generated by the Python
`direct_gate_schedule.py` checker and compared with native exported topology;
the Lean role theorem does not reimplement that constant derivation. Native
column and PCS authentication are separate obligations.

The pinned native source-cell exports also pass a separate Lean role check:

| Native fixture | Source gates | Add / pointwise | Add partition `A` | Source row bands | Constant add rows |
| --- | ---: | ---: | ---: | --- | ---: |
| `case00` | 1 | 0 / 1 | 475 | pointwise `503` | 464 |
| `case07` | 8 | 5 / 3 | 473 | add `3..7`, pointwise `501..503` | 457 |
| `case14` | 15 | 7 / 8 | 468 | add `3..9`, pointwise `496..503` | 450 |
| `case16` | 16 | 10 / 6 | 470 | add `3..12`, pointwise `498..503` | 449 |

`GeneratedNativeFullRowRoles.lean` checks each literal native source cell
against the independent `rowRole` function, exact selector flags, the
source-derived expected cell list, and the constant-add count. The pinned
exports cover four program sizes; the general theorem applies to any source
admitted by the Lean byte checker, subject to its stated model boundary.
