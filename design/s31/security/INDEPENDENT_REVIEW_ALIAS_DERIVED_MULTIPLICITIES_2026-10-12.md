## What the theorem actually establishes

- `addressSchedule` sets each supplied island `mults` to zero before constructing the read list. `derivedIsland` then fills every island count with `List.count` over both operands of **all** joined projected and island rows plus the nine public output feeder addresses `[2,3,4,5,6,7,8,9,10]`. Repeated operands count twice; unused outputs get zero. `projectedCountsCheck` independently checks the projected rows' source-derived counts against that same global list. `check_ignores_supplied_multiplicities` proves that changing only input island counts cannot change acceptance.
- `check` is an executable conjunction: the constant-island row/selector/address/value/arithmetic certificate, projected count equality, and the bounded exact address ledger. Its premise does **not** assume the desired Gate balance or the claimed multiplicity equality. `checked_joined_has_read_counts` covers both halves of the joined roster; `checked_alias_derived_full_modeled_trace` then reuses the pre-existing full-model construction to produce one 512-row synthetic trace with vanishing local arithmetic roots, selected output, input boundary, and ideal Gate event balance.
- The check is demonstrably satisfiable on the pinned case07 island. With the cached formal build, evaluating `check case07Certificate constantCells nativeValues`, `projectedCountsCheck case07Certificate constantCells`, and the derived-island address ledger returned `true`, `true`, and `true`. Independently, `alias8_derived_multiplicities.py` checked all 512 diagnostic fixed rows against the 1,033 read occurrences and rejected one changed diagnostic multiplicity.

## Scope and remaining proof obligations

The island's row roles and three address columns remain supplied data, checked by `NativeConstantIslandCertificate`; this module does not derive their exact values from Zig's constant/padding generator. The finite `nativeValues` table is likewise supplied and locally checked. The result constructs a trace from these checked cells; it does not identify that trace with native committed main or fixed columns, nor derive the check from verifier acceptance. The case07 diagnostic and fixed-root regression are concrete tests, not a generic PCS-opening theorem. The conclusion's `balanced` predicate is exact ideal event permutation, not native LogUp, Fiat–Shamir, FRI, or STARK soundness. These limits are accurately stated in the module and its companion documentation.

Zig's direct arithmetic emitter starts from `CircuitView.computeUses`, which counts gate operand occurrences and circuit public outputs; it separately adds permutation-row uses at address zero. This Lean model applies to the bounded S31 direct-Gate shape with no permutation rows and the fixed nine public output feeders. A compiler-to-native theorem must prove those profile facts and the equality between emitted fixed multiplicities and this read-count function for every admitted source, then connect authenticated openings to the checked synthetic trace.
